===============
wsipipe-isyntax
===============

An extension to wsipipe to use Philips isyntax format

Installation:

wsipipe isyntax needs python 3.6 or lower.
need to uninstall opencv-python-headless from wsipipe and install lower version opencv-python-headless==4.1.2.30

need to copy files from /mnt/isilon1/philips_isyntax to 
/home/user/.conda/envs/env_name/lib/site-packages/python3.6/wsipipe_isyntax/load/slide/libraries
